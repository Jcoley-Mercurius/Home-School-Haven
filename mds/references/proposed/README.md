# Proposed public-page visual references

**Status:** Proposed — not approved, not canonical.

These images are working visual proposals for public pages that MDS v1.0 does not
yet cover with an approved reference. They are **not** listed in
`mds/references/REFERENCE-INDEX.md` and carry no MDS-REF ID, because adding a
canonical reference is an approved-design-state change owned by MDS governance.

| File | Page |
|---|---|
| `public-about-proposed.png` | Public about |
| `public-resources-proposed.png` | Public resources |
| `public-contact-proposed.png` | Public contact |

`public-calendar-proposed.png` was approved by the owner on 2026-08-28 and is no
longer in this set. It now lives at
`mds/references/assets/public-calendar-reference.png` as **MDS-REF-010**.

Do not implement against the remaining images as authority. The approved MDS specification,
tokens, and canonical references in `mds/references/assets/` remain the design
authority. If the owner approves any of these, promote the file into
`mds/references/assets/` and register it in the reference index with an MDS-REF ID.
