# Home School Haven Workflow Catalog

| ID | Workflow | Completion truth |
|---|---|---|
| MPS-WFL-001 | Program discovery and conversion | Family receives confirmation and a clear next step |
| MPS-WFL-002 | Family account and student-profile onboarding | Parent reaches family-ready state or sees a truthful blocker/recovery path |
| MPS-WFL-003 | Enrollment and existing-provider payment | One authoritative enrollment state; confirmed roster only when justified |
| MPS-WFL-004 | Discounted-class assistance | Private owner/admin review; no automated eligibility decision |
| MPS-WFL-005 | Program administration and publishing | Consistent public/private program truth with retained history |
| MPS-WFL-006 | Educator program delivery | Assigned families receive authorized scoped content |
| MPS-WFL-007 | Family participation | Parent sees current program state and next action |
| MPS-WFL-008 | Foundation beta review | Samantha classifies and approves dispositions without silent scope growth |

Each workflow's triggers, preconditions, alternate/failure paths, states, notifications, owners, and recovery behavior are authoritative in `MPS-PROJECT-STATE.yaml`. Implementations must not substitute a screen list for these stateful flows.
