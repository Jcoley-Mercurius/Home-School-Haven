# Home School Haven Scope and Release Plan

## Foundation Release — Must

Responsive public website; program catalog/details; inquiry, tour, guidance, and private assistance; external-checkout registration; parent family account and student profiles; family dashboard; administrator operations; assigned educator workspace; announcements/resources; parental consent and role-appropriate privacy; truthful pending/failure/recovery states; audit history; responsive and accessible use.

## Should

Attendance, capacity/waitlist management, invited secondary guardian, email notifications, calendar download, payment-status visibility, and basic beta reporting. Implement only after Must workflows are stable and dependencies are understood.

## Could

Saved programs, sibling shortcuts, reusable program templates, scheduled announcements, downloadable documents, internal notes, and structured owner-feedback capture.

## Won't this release

Independent student accounts, full LMS authoring/Course Builder, full self-paced delivery, automated financial-assistance or refund/cancellation/credit/transfer decisions, rebuilt payment processing, broad production analytics, and complete-platform public launch.

## Release progression

Foundation Release → Samantha walkthrough and classified feedback → MPS update/approval → Complete Platform Launch definition. Open policy and activation controls must be resolved before real-family use.
