# MPS `AGENTS.md` Template Guidance v1.0

Merge MPS, MDS, and MTS instructions into one project-level `AGENTS.md`.

Include:

1. Product and active MPS/MDS/MTS versions
2. Product purpose, users, outcomes, and release scope
3. MPS authority and artifact paths
4. MDS authority and artifact paths
5. MTS authority and artifact paths
6. Approved workflows, state models, rules, and acceptance criteria
7. Decisions already made and explicit exclusions
8. Traceability requirements
9. Product, design, and technology gap protocols
10. Implementation workflow and approvals
11. Required engineering, acceptance, visual, accessibility, security, and manual checks
12. Completion report and combined definition of done

Include:

> **You implement approved product requirements. You do not invent product policy.**

Use:

**READ → TRACE → INSPECT → COMPARE → PLAN → APPROVE → IMPLEMENT → VALIDATE → REPORT**

Require substantial plans to name requirement/rule/acceptance IDs, MDS/MTS dependencies, repository evidence, files expected to change, assumptions, risk, migration/rollback, acceptance checks, and exact manual test steps.

Require completion reports to include what changed, linked IDs, tests and actual results, external setup, product/design/technology gaps, deviations, and user decisions still required.
